Project Brief & Operations

Executive Methodology Overview

This project serves as an operational proof-of-concept demonstrating how real-time cloud data pipelines can monitor critical public utility infrastructure. It is designed to model systemic data management workflows required in modern logistics, asset management, and geographic research frameworks.

📊 Data Metrics Decoded

  • Carbon Intensity: Measured in gCO₂eq/kWh. It reflects the weight of greenhouse gas emitted to produce a single kilowatt-hour of electricity. Lower scores mean cleaner local operations.
  • The Power Mix Matrix: Compares high-emission fossil generation (natural gas combustion assets) against renewable generation (hydroelectric run-of-river and reservoir assets).

⚙️ Pipeline Architecture

  • Asynchronous Queries: Uses JavaScript promises and browser fetch APIs to query REST endpoints every 5 minutes without disrupting UI processes.
  • Data Normalization: Raw multi-variant metrics from API playbooks are programmatically aggregated and cross-calculated to maintain true proportional balances totaling exactly 100%.
