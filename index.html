Project Brief & Geographic Context

Nigeria National Grid Analysis

This dashboard tracks the real-time electricity telemetry of Nigeria (NG Zone). In a rapidly developing economy, stabilizing public utilities and managing energy logistics requires real-time overview parameters. This artifact functions as an administrative project framework detailing structural power generation and environmental footprints across the country.

🇳🇬 Local Grid Realities & Systemic Impacts

Thermal Gas Dominance Nigeria’s baseline power grid depends heavily on natural gas-fired thermal power stations (such as Egbin, Afam, and various NIPP plants). This creates a high, continuous carbon footprint, meaning the grid's average carbon intensity remains consistently elevated when gas turbines supply the primary bulk load.
Seasonal Hydro Variation Clean renewable input flows from major hydroelectric plants (like Kainji, Jebba, and Shiroro dams). The generation balance shifts radically based on seasonal cycles—wet seasons boost hydro capacity, lowering overall carbon intensity, while dry seasons stress baseline thermal output.

📊 The Infrastructure Metrics

  • Carbon Intensity: Calculated via global lifecycles in gCO₂eq/kWh. Tracking this value reveals how directly fuel supply chain variations affect national environmental targets.
  • Systemic Grid Vulnerability: Real-time mapping of gas vs hydro outputs allows administrators to predict potential fuel constraint bottlenecks or operational load sheds across distribution networks.

⚙️ Pipeline Architecture

  • Asynchronous Telemetry: Uses clean, non-blocking JavaScript ES6 Fetch protocols to map data matrices dynamically every 5 minutes without disrupting administrative site interfaces.
  • Proportional Scaling: Modifies raw multi-variant API response tokens into clean, normalized visual values that maintain strict mathematical precision, adding up to 100%.
